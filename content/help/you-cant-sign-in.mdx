Every Partyreel account opens with an email code, with Google right beside it; a password is a quiet fallback for anyone who set one (see [sign in: a code, Google, or a password](/help/sign-in-options-and-passwords)). If one way won't open, another almost always will, and they all lead to the same account when the email matches.

## The password doesn't work

A password sits behind <UiLabel>Have a password? Use it instead</UiLabel>, under the code field; most people never open it. If you do, and it refuses you, the message reads <UiLabel>That email and password didn't match.</UiLabel> It's deliberately vague: it won't tell you whether the email is unknown, the password is wrong, or the account never had a password (accounts created with a code or Google don't, until you add one).

Three buttons sit right under it: <UiLabel>Send a new code</UiLabel>, <UiLabel>Set a new password</UiLabel>, and <UiLabel>Continue with Google</UiLabel>. You can also skip straight to a reset: <UiLabel>Forgot password?</UiLabel> next to the password field emails a code before you even try, and verifying it lands you on a screen to pick a new one. Once you're in, the <UiLabel>Password</UiLabel> card on your account page changes it any time.

## The sign-in link expired

Tapping an old link from an earlier email shows <UiLabel>That sign-in link has expired.</UiLabel> right on the sign-in door, which is still standing there waiting: enter your email again for a fresh code, or tap Google. Only the newest code is ever valid.

## The code doesn't verify

Six digits that don't match the one just sent show <UiLabel>That code didn't work.</UiLabel> with three ways out beneath it: <UiLabel>Try again</UiLabel>, <UiLabel>Resend the code</UiLabel>, and <UiLabel>Use a different email</UiLabel>. An older code from the same inbox never works once a newer one has been sent.

## The code never arrives

See [the email code didn't arrive](/help/the-email-code-didnt-arrive).

## "My events are gone"

You're almost certainly in a different account. Partyreel matches accounts by email, exactly: `you@gmail.com` and `you+party@gmail.com` are two accounts, and so are a work and a personal address. Sign out, sign back in with the address you used when you created the event, and it's there. Google sign-in uses the address on the Google account you pick.

## Two accounts by accident

If you've ended up with events split across two addresses, [send us a note](/contact) from both and say which one you'd like to keep; we'll sort it out. There's no self-serve merge yet.

<Callout type="info" title="Signed out unexpectedly?">

Sessions do expire after a long while, and signing out on the event page also clears your guest access to that event. Sign back in and you're where you were.

</Callout>
