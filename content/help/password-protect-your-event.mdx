A password puts a door on the link: the event's name and photo count show on the outside, and everything else waits until a guest types the password from your invitation.

<Path>Dashboard › Your event › Settings › Visibility & access › Password</Path>

## Set a password

Password protection comes with <PlanBadge tier="paid" />. Choose <UiLabel>Password</UiLabel> under <UiLabel>Who can see this album?</UiLabel>, type a password of at least <PasswordMinLength /> characters, and tap <UiLabel>Set password</UiLabel>. Setting it switches the event to password visibility in the same step. The card then reads <UiLabel>Password is set</UiLabel>.

Partyreel never shows the password again, so write it down where you'll find it: it's the one thing to share with guests separately from the link, on the invitation or by message.

## What guests see

The locked page shows the event's name and how many photos are inside, over a ghosted grid. They tap <UiLabel>Unlock</UiLabel> after entering the password and the album opens. It stays open on that device for about <UnlockHours />, then asks again. A wrong password gets a gentle retry; five wrong tries in a row pause things for a few seconds. See [messages guests might see](/help/messages-guests-might-see).

If the event also requires accounts, the password comes first and the email check second.

## Change or remove the password

<UiLabel>Change</UiLabel> sets a new password immediately; guests already inside stay inside until their unlock expires, then need the new one. <UiLabel>Remove</UiLabel> takes the password off and returns the event to public. Both save on their own, without the page's Save button.

## Two things to know

- **Uploads respect the lock.** Nobody can add a photo without having unlocked the album, even with a link that was working before you set the password.
- **On the free plan later**, an existing password keeps working and can still be removed; you just can't set or change one until you're back on a paid plan.

<Callout type="tip" title="Password or Private?">

A password is for guests you want inside without a Partyreel account: it's a door with a key. Private is a wall: only you. Curate on Private, then open up with a password when it's ready.

</Callout>
