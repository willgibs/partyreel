Some events ask guests to confirm an email before uploading. You enter your address, we send a short code, and you type it in on the same screen. Most codes land within a minute; when one doesn't, work through this list.

## Check these first

1. **Look in spam and promotions.** A first email from a new sender is the classic filter victim. Search your inbox for "Partyreel" to be sure.
2. **Re-read the address on the code screen.** The screen shows exactly where the code went. A one-letter typo is the most common cause, and the fix is to go back and enter the address again.
3. **Give it a minute, then request a new code.** Delivery can lag on busy networks and some providers. Use the newest email once it arrives.
4. **Work or school inbox? Try a personal one.** Corporate mail systems sometimes quarantine automated messages, which matters at conferences especially.

## If it still won't come

Your photos aren't going anywhere: whatever you selected is still on your phone, so you can join again and upload once you're in. If codes repeatedly fail to arrive for an address that you know is right, [tell us](/contact) which event you were joining and roughly when you tried, and we'll dig in.

## A note for hosts

Guests only see this step when your event requires accounts, which is the default for new events. It's the setting that puts a verified name and email behind every upload; the trade is this one extra step at the door.
