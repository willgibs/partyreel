Your event's QR code is its permanent link, drawn so a phone camera can read it. It's created with the event, it's ready the moment you finish the wizard, and it never changes, whatever you do to the event afterward.

<Path>Dashboard › Your event › Share</Path>

## The share dialog

<UiLabel>Share</UiLabel> on the event page (or the small QR chip on the dashboard card) opens the code and the link side by side. The copy button beside the link puts the address on your clipboard for the group chat or an email. See [send the event link](/help/send-the-event-link).

## Pick a style

Tap <UiLabel>Customize</UiLabel> and choose one of four looks:

- <UiLabel>Classic</UiLabel>: clean black and white.
- <UiLabel>Bold</UiLabel>: brand-accent corners.
- <UiLabel>Rounded</UiLabel>: soft and celebratory.
- <UiLabel>Dots</UiLabel>: playful dots.

Tap <UiLabel>Save QR style</UiLabel>. The style is saved to the event and used everywhere it's shown, including the <UiLabel>Invite</UiLabel> button guests see on the event page. Every style keeps dark squares on a white background, because that's what scanners need; color only ever touches the corner squares.

## Download it

Two formats, and the choice is about where it's going:

- <UiLabel>SVG (best for print)</UiLabel> scales to any size without going soft. Use it for table cards, posters, and anything a printer touches.
- <UiLabel>PNG (best for screens)</UiLabel> for slides, a TV loop, or pasting into a document. It's small (about 200 pixels across), so if the code will be bigger than a thumbnail on screen, use the SVG there too.

Both come with the quiet zone (the white margin) built in. Keep it when you place the code. Printing and screen tips are in [print your QR, or put it on a screen](/help/print-or-display-your-qr).

## What you can't change

The code encodes the permanent event link, so it stays valid even if you later add a custom link or change the event's name. There's no logo overlay, no color picker, and no template gallery in the app. If you want the code inside a designed card, drop the SVG into whatever tool you're designing in.

<Callout type="tip" title="One code, many places">

You don't need a different code per table. Print the same one as many times as you like; they all open the same album.
