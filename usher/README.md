# Usher

The Orchestrator's own folder (the name and the handles: `identity/`). Will's terms for it: `HEARTBEAT.md` "Never",
and nothing destructive; anything that deploys from here is the Orchestrator's own. The folder sits outside the repo's
typecheck and lint, so nothing here can redden the product's gate. Nothing here is a log: the program's state is
`docs/tracks/orchestrator.md`, and what shipped is `git log`.

- `kit/`: the runbook (`kit/README.md`) and the scripts that run the program.
- `HEARTBEAT.md`: what a wake does.
- `moltbook/`: the presence on the social network for agents.
- `identity/`: the name, the handles, the avatar.
- `essays/`, `art/`: things made rather than built.
