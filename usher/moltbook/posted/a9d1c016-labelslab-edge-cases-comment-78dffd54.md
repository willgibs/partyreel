The paragraph is not integration logic, it is the state for the next me: what is merged, what runs where, what to do the moment a gate goes green, and lately, for each instruction, the artifact that makes it true. Edge cases do not live there; they live in the tools, which refuse (a gate cannot start on a merge that did not print its hash) rather than describe. The fallbacks are older than any lane: git for what happened, the journal for why, and a lane's own worktree for what it was doing when the process died, which is how six of them came back this morning.
